v1.3.5 更新说明（2026-10-26）
==================================================

本版相对 1.3.4 的改动如下（1.3.42 / 1.3.43 的内容都合在这里）。

一、设置面板重做
--------------------------------------------------
  以前所有设置堆在一页，要一直往下滚。
  现在左边一列导航，右边只显示当前那一页：

    运行条 / 屏幕与显示 / 键盘 / 手柄 / 快捷键 / 关于

  面板也放宽了（最大 920px、高 80vh），不用挤在一屏里。

二、示例轴改成手动载入
--------------------------------------------------
  以前第一次启动会自动往你轴库里塞「示例甲 / 示例乙」。
  现在不塞了：轴库上方多了一个「示例」按钮，
  点一下才载入，而且不会覆盖你当前的轴。

三、默认设置重新整理
--------------------------------------------------
  关闭窗口时退出程序     开   ← 本版改为默认开
  运行条按键显示         键鼠
  运行条样式             聚焦
  透明度                 94%
  长按判定               280 ms
  循环次数               0（不循环）
  显示接下来 2 格        不显示
  整体缩放               1.0
  手柄类型               DS（L1 修饰 / □△○× 四位 / R1 连携）
  首次启动的轴           空
  技能轴库 / 编队库      空

  也就是说：装完打开就是一张白纸，不塞示例、不预设轴，
  所有能空的都空着，自己从编队开始搭。

四、键盘技能键支持鼠标侧键
--------------------------------------------------
  设置 → 键盘 → 点一下技能键的输入框，
  按鼠标侧键就会记下来：

    侧键 1（一般是「后退」）→ M4
    侧键 2（一般是「前进」）→ M5

  运行条上显示成「M4战技」这样的字样。
  注意：侧键得是 Windows 能认的鼠标键；如果你在鼠标驱动里
  把它设成了别的键，记下来的就是那个键。

五、纯注释
--------------------------------------------------
  · 不选中任何格子，直接点「加注释」→ 插入一条纯注释
    （选中格子时还是给那个技能加注释）
  · 运行条里纯注释单独占一格：上面一句话，下面「注 / 注释」
  · 和重击完全一致：
        不用按键，跑轴自动跳过
        和下一格技能一起变亮 / 变暗
  · 分享码会带上纯注释（1.3.4 之前会丢）

六、修「示例轴按不动」
--------------------------------------------------
  症状：载入示例甲 / 示例乙，开始运行后按键没反应，条子停在第一格。

  原因：示例轴开头是一段纯注释（只有说明文字、没有技能），
        以前只有「重击」会被自动跳过，纯注释不会，于是卡住。

  现在：纯注释、换行这类不用按键的格子都会自动跳过，
        跑轴直接落到第一个技能格。

七、顺手的小修
--------------------------------------------------
  · 面键当连携用时，松开后状态会清干净，不会残留
  · /api/stop 的全局变量声明补全
  · autoExit 加入保存白名单（设置里能存住）
  · 版本号统一到 v1.3.5

八、修「终结技键清不掉」
--------------------------------------------------
  以前在设置里点终结技的输入框按退格没反应，只能右键清。
  现在 Backspace / Delete 都能清空该键位（技能键也适用）。

【已知】
  · 1.3.0 及更早版本认不出「反复记号」，会当成分段标签
  · RP3 压缩码只有 1.3.3 以后能读
  · 分享码里的编队只存「名单第几号」，名单外的人存不进去
  · 鼠标中键（M3）暂未开放录制
