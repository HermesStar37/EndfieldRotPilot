运行条上显示什么
只改条上写的键名，键鼠和手柄始终同时生效。
聚焦 = 当前步高亮、其余变淡；框选 = 只给当前步加框；兼容 = 两者都做。
键盘
点一下输入框，按下想用的键即可（终结技键按 Backspace 可清空）。
快速输入
Q + 1~4 战技　·　E + 1~4 连携　·　Alt + 1~4 终结　·　H 重击
前三个都是「按住不放再按数字」，松开就失效；单独按数字不会插入技能。
手柄
点「刷新」检测
—
先选 DS / Xbox（会自动识别），下拉里只会有这套手柄能用的键。
连携键可以和某个面键设成同一个：按住修饰键 + 面键 = 战技，单按面键 = 连携。
终结技也可以用手柄组合键：L1 + R1 + 面键（Xbox 是 LB + RB + 面键）， 和 Alt + 1~4 效果一样。
快捷键
键鼠和手柄同时生效，两套都能用。F10 / F11 只在运行条跑着的时候有用。
反复记号在哪设
反复（重复记号）不在这里设：在技能轴底部点「反复」， 在要回头的地方插两个记号配对即可，次数直接点数上的 － / ＋。
