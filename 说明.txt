终末地 · 技能轴 Endfield RotPilot
使用说明（v1.4）
==================================================

免费同人工具，游戏素材版权归鹰角网络所有，请勿商用。

【重要声明】
  本工具是第三方辅助工具，非官方出品，与鹰角网络无任何关系。
  使用时请自行判断风险：不排除被游戏或反作弊系统检测的可能。
  本质是“按键捕捉 + 显示提示”，不碰游戏进程、不注入 dll、不改内存，
  但由此导致的封号、警告、数据异常等后果仍由使用者自行承担。


一、第一次使用
--------------------------------------------------
1. 把整个文件夹解压到任意位置（路径里不要有特殊符号）。
2. 双击「启动.bat」。
3. 弹出系统权限窗口时点「是」。
   程序需要管理员权限，否则读不到游戏里的按键。
4. 稍等一两秒，会出现一个没有地址栏的窗口，这就是主界面。
5. 第一次打开时轴是空的，先做两件事：
   · 左边编队点 1~4 号位，选 4 个干员
   · 右边底部点「战技 / 连携技 / 终结技」下面的图标加技能
   加完点右上「开始运行」，按提示条上的键就能跑。

退出方法：
  默认「关闭窗口时退出程序」是开着的 —— 直接叉掉主窗口，
  后台和那个最小化的黑窗口一起关。
  不想这样的话：设置 → 关于 → 取消「关闭窗口时退出程序」，
  之后关窗口只关界面，刷新页面能回来。
  也可以点右下角「退出程序」，效果一样。
  Ctrl+R 刷新页面不受影响。


二、主界面
--------------------------------------------------
左边是「编队」，右边是「技能轴」。

编队
  1~4 号位     点一下，在弹出面板里选干员
               同一个干员再点一次 = 取消该位置
  快捷编队     连续点卡片，按顺序填进空位
  添加干员     选一个干员包（.zip），装好立刻可用
  清空         四个位置一起清空

技能轴
  底部一排按钮用来往轴上添加内容（设置分成七页，见第十六节）：
    战技 1~4     对应编队 1~4 号位的战技
    连携技 1~4   对应编队 1~4 号位的连携技
    终结技 1~4   对应编队 1~4 号位的终结技
    重击         只做提示，不需要按键（见第六节）
    加注释       在轴上写一句提醒
    插入分段     把轴切成几段，运行时分段显示
    反复         插入反复记号（见第五节），两个记号配对后中间那段就会反复
    换行         分段内的换行（轴上会画一条虚线，标着「↵ 换行」）

  编辑操作：
    点格子之间的空隙   出现光标，新技能插在光标处
    点「↵ 换行」       光标落到下一行行首，新技能从下一行开始
    换行右侧的 ×       删除这个换行（可撤销）
    单击技能           选中；光标落到它后面，接着按 Backspace 删的就是它
    再点一次           取消选中
    拖动技能           改变顺序
    双击分段/注释      改名
    Ctrl+点击          同时选中多个技能
    删除所选           删除选中的技能（可批量）
    左移 / 右移        移动选中的技能（可批量）
    Ctrl+Z             撤销（可连续撤销多步）
    Ctrl+Y             重做（Ctrl+Shift+Z 也可以）
    Ctrl+C / X / V     复制 / 剪切 / 粘贴
    Delete / Backspace 有选中先删选中的，没选中才删光标前一个

  撤销覆盖范围：加/删技能、加/删换行、剪切、粘贴、移动、改注释、
  改分段名、清空序列、载入别的轴 —— 都能撤回来。

  键盘快速输入（不用点底部按钮）：
    1 / 2 / 3 / 4         战技 1~4
    Alt + 1 / 2 / 3 / 4   终结技 1~4
    E 然后 1 / 2 / 3 / 4  连携技 1~4（按 E 后 1.2 秒内按数字）
    H                     重击

· 换位置：把编队里的一张卡拖到另一张上，两人互换位置，
  轴里的图标不变（技能跟着人走，不会错位）。
· 按键输入：按住 Q 再按 1~4 = 战技，按住 E 再按 1~4 = 连携，
  Alt+1~4 = 终结技，H = 重击。
  和 Alt 一样是「按住 + 按数字」，松开就失效；单独按数字不会插入技能。
  按 E 不再弹提示，直接按数字即可。



三、开始运行
--------------------------------------------------
点右上角「开始运行」，编辑窗口会最小化，
屏幕上方出现一条技能提示条，按轴一步步往下走。
跑完会自动收起。

过程中可以随时：
  点「停止运行」   提前结束
  按 F8            提前结束
  按 F9            回到第一段开头


四、提示条：样式、位置、透明度
--------------------------------------------------
样式（设置 → 屏幕与显示 → 当前技能突出显示）：
  聚焦（默认）   只把当前该按的技能点亮，其它变暗
  框选           所有技能一样亮，当前那格加了蓝色底
  兼容           既变暗，当前那格也有蓝色底

位置和大小：
  设置 → 运行条（大小 / 整体缩放）、屏幕与显示（距顶部 / 水平位置）。
  整体缩放（0.7~1.5）会连字号、间距一起放大缩小，小屏大屏都好调；
  嫌条太长可以关掉「显示接下来 2 格」——那两格是淡一点、小一号的预告，
  跑连招时能提前看到下一步按什么。
  提示条也能按住拖动：松手就记住，下次还在原地（跨屏幕也记得在哪块屏）。
  想精确手填，就用设置里那两个数字。

透明度（三种改法，随时生效）：
  1. 主界面「技能轴」标题行右边有滑块，10%~100%，
     运行条正在跑时拖它立刻变；
  2. 设置 → 运行条 → 不透明度，填数字（0.30~1.00）；
  3. 游戏里按 F6 变淡 / F7 变实（每次 10%，条上会闪一下当前百分比）。
  键位都在「设置 → 快捷键」里改。

右键提示条：下一段 / 上一段 / 回到开头 / 打开主界面 / 关闭运行条。


五、双屏 / 多显示器
--------------------------------------------------
默认就是「跟随游戏窗口」：程序会找游戏窗口（进程名或标题里带 Endfield / 终末地），
把主窗口和提示条都摆到游戏所在的那块屏上。

设置 → 屏幕与显示 → 运行时放在哪块屏，三选一：
  跟随游戏窗口（推荐）  游戏在哪块屏，辅助窗口就在哪块屏；
                        游戏换屏了，它们也跟着挪（只在你没手动拖过时跟）。
                        找不到游戏窗口时，先用上次那块屏，再不行用主屏。
  主屏                  固定在第一块屏
  副屏                  固定在第二块屏（接了三块以上就取第一块非主屏）

改了立刻生效（不用点保存），窗口会直接挪过去。

记住位置和大小：
  主窗口每次关掉时都会记住位置、大小、在哪块屏，下次在同一块屏上原样恢复。
  最大化也会被记住：最大化着关掉，下次就最大化着打开；
  把它拖回普通窗口也一样记住，之后不会再被推回最大化。
  换了屏幕布局（拔了副屏、改了缩放）也不会跑到屏幕外——超出部分会自动收进工作区。
  提示条拖到哪儿也记住（含在哪块屏）。

最大化 / 全屏随便用：
  开窗口后有十几秒是程序在“摆位”，这段时间也会让着你——
  你点了最大化、或者按 F11 全屏，它就直接收手，不会把窗口再改回去。

缩放不同（比如主屏 200%、副屏 100%）：
  程序按“物理像素 + 各屏自己的工作区”算位置，不会因为缩放差异而漂移或出屏。

不抢焦点：
  挪窗口、保持置顶都用“不激活”的方式，切回桌面、游戏切全屏/窗口化时，
  提示条仍然留在原屏最上层，不会把游戏切出去。

如果游戏没被认出来（标题/进程名里没有 Endfield 字样）：
  设置里的「显示屏幕」会显示“没认出游戏窗口”。这时先手动拖到副屏一次，
  它会记住那块屏；下次用「跟随游戏」时就会回到这块屏。

六、反复记号（乐谱式：可嵌套、一个起点可带多个终点）
--------------------------------------------------
反复不在「设置」里设，而是像乐谱的反复记号一样直接写在轴上。
一对记号圈住中间一整段：跑到「终点」就跳回「起点」，这一圈打 N 遍。

  懒得看文字：技能轴库右上角点「示例」，会放进两条教学轴 ——
  「示例甲 · 基本操作与循环」（第二节就是一个排好的 ×2 循环）、
  「示例乙 · 嵌套 / 多终点 / 无限」。点条目载入，照着跑一遍比看说明快。
  新装默认不带这两条（免得把轴库弄乱），需要时点一下就行；不想要了点条目上的 × 删掉。


  最基本的用法：
    1. 光标放到“从哪开始回头”的位置（点格子之间的空隙）。
    2. 底部点「反复」→ 插入记号（显示「↻ 反复（未配对）」）。
    3. 光标放到“回头到哪结束”，再点「反复」→ 再插一个。
    4. 点第一个记号（变虚线框）→ 点第二个记号 → 配成一对。
    5. 次数在「终点」那行点「－ / ＋」改，或双击输入。
       次数含第一遍：×3 = 这一段一共打 3 遍。
       点「∞」= 无限循环（显示 ×∞），再点一下回到 2 遍；双击时填 -1 或 ∞ 也一样。

  一个起点可以带多个终点（重点）：
    同一个起点下面可以挂好几段，每段各记各的次数。
    做        法：光标放到新的结束位置 → 点「反复」插入记号
                → 点起点上的「＋ 终点」→ 再点那个新记号，就挂上了。
    效果       ：跑到哪个终点，就跳回这个起点；每个终点的次数互不影响。
    举例       ：起点在开头，终点 A 在中间（×2）、终点 B 在结尾（×3），
                就是“开头到 A 打两遍，再从头跑到 B，整段打三遍”。
    显示       ：起点那行会多一个「2 个终点」的黄色小标。

  嵌套（反复套反复）：
    记号可以层层套，内层在外层每一遍里都重新计数，跟乐谱一样。
    层数用缩进和颜色区分；起点后面写「↓ 到终点为止（N 步）」，
    终点写「↑ 跳回起点（第 X 层）」。

  反复可以跨分段：
    记号可以在第 1 段里起、在第 3 段里止，中间隔几个分段都没问题。
    想整条循环：最前面和最后面各插一个、配对即可。

  看范围：
    鼠标停在任意一个已配对的记号上，它圈住的整段会一起点亮，
    一眼能看出这对记号管到哪儿。

  删除：
    记号右边的「×」：删终点只删这一段；删起点会把整组（含所有终点）一起删。
    选中记号按 Backspace / Delete 同理。Ctrl+Z 能救回来。

  无限循环（－1 次）：
    把某一段的次数设成「∞」（双击填 -1 也行），它就会一直反复下去，
    只有按 F8 / 「停止运行」才停。条上会闪「反复 ∞（第 N 遍）」。
    整条轴都想要无限：最前和最后各插一个记号、配对，然后把终点设成 ∞。

  运行时的表现：
    跑到「反复终点」自动跳回「反复起点」，条上闪「反复 2/3」，
    多层嵌套时还会标出「第 X 层」；次数跑完就继续往下走。

  快捷键（设置 → 快捷键 里可改）：
    F10   临时开/关反复（只影响本次运行，不改轴；关掉就是一遍直过）
    F11   立刻回到最内层反复的起点（不在反复里就回本段开头）

  注意：
    两个记号之间必须有技能，空的配了也不会反复（会直接拦下来）；
    内层设了∞，外层就永远等不到它跑完——想“练一会儿再继续”别把内层设成∞；
    两段不允许交叉（A 起 B 起 A 止 B 止），会提示换一对；
    终点必须放在起点下面。

七、重击
--------------------------------------------------
有些角色的循环里要穿插重击，但它不需要按任何键。

在底部点「重击」会插入一格灰色图标：
  运行到它时不会停下，直接跳到下一个技能；
  显示上它跟着后面第一个真正的技能一起亮或变暗。
所以它只起“这里要打重击”的提示作用。


八、键盘 / 手柄
--------------------------------------------------
键盘和手柄同时生效，不需要切换。

默认键位（Q / E / Alt 都是「按住不放再按数字」）：
  Q + 1~4          战技 1~4
  E + 1~4          连携技 1~4（松开 E 就失效）
  Alt + 1~4        终结技 1~4
  长按 1~4         终结技 1~4（另一种方式）
  单独按 1~4       不会插入技能，必须先按住 Q / E / Alt
  H                重击
  F8 / F9          退出运行 / 回到第一段
  F8               退出运行
  F9               重置到第一段
  F10 / F11        临时开关反复 / 回反复起点
  F6 / F7          提示条变淡 / 变实

修改方法：
  设置 → 键盘 → 点一下输入框，按下想用的键，会自动记录。
  终结技留空 = 长按对应的战技键。
  想清掉某个键：点输入框按 Backspace / Delete，或者右键点它。

手柄：
  设置 → 手柄，先点「DS」（PS5）或「Xbox」，下方的「当前按下（实时）」
  会显示你正在按的键；改完点保存。
  程序也会按检测到的手柄名字自动判断类型。

  DS（PS5）默认：L1 按住 + □ △ ○ × = 1~4 号位，R1 = 连携技
  Xbox 默认    ：LB 按住 + X Y B A = 1~4 号位，RB = 连携技

  连携技可以单独改：Xbox 支持 A / B / X / Y（也保留 LB / RB / LT），
  DS 支持 L1 / R1 / L2。改了之后运行条按「手柄」显示时会同步显示新键位。
  同一个面键既当 1~4 号位又当连携时不会打架：
    按住修饰键 + 面键 = 战技
    单按面键         = 连携

  键盘也能用鼠标侧键：设置 → 键盘，点技能键的输入框，
  按鼠标侧键会记成 M4（侧键 1）/ M5（侧键 2）。

  手柄按了没反应，按顺序检查：
    1. 是不是用「启动.bat」以管理员身份打开的
    2. 「当前按下（实时）」有没有跟着变
    3. 游戏里手柄模式是否开启
    4. 无线手柄是否已连接、电量是否正常
    5. 有些游戏会独占手柄，可装 DS4Windows 转成 XInput 再试


九、编队库 / 技能轴库
--------------------------------------------------
左侧分两块：

  编队库
    「保存当前编队」把 4 人组合存起来并起名；
    点某套编队 = 载入，同时下面的技能轴库只显示用这套人存的轴；
    点「全部」取消过滤；× 删除。

  技能轴库
    上面有个搜索框：输轴名或干员名就能筛出来（轴多了不用翻）；
    右上「示例」放进两条教学轴（新装不带，想看循环怎么排就点它）；
    「备份」把所有轴和编队导成一个 .json 文件，「恢复」从文件读回来
    （同名会加序号，绝不覆盖你现有的）—— 换电脑、重装就靠这两个。
    「保存」把当前编队 + 整条轴存进去；
    如果当前就是从库里载入的，会问「覆盖」还是「另存」——
    弹窗里会写清两边各多少格；内容一点没改的话直接提示，不弹框；
    覆盖之后按 Ctrl+Z 还能把原来的内容找回来。
    点条目载入，双击改名，× 删除。
    「分享码」导入的轴会自动带着名字存到这里（见第九节）。


十、分享与导入
--------------------------------------------------
分享码
  点「分享码」→ 弹窗里最上面是「轴名字」，默认就是当前这条轴的名字，
  想改直接改（改完分享码会自动重新生成）→ 复制发给别人。

  导出格式：两选一，下面那行小字会跟着解释。
    RP2 · 兼容（默认，推荐）
        连注释一起发，前缀 RP2。作者原版和所有老版本都能导入，
        只是它们看不到轴名（轴本身、编队、反复记号都在）。
    RP3 · 压缩
        内容全在（注释也在），码短一截，前缀 RP3。
        只有新版本（1.3.3 及以后）能读；老版本会报“版本不支持”，
        不会像以前那样甩一串 bad base85。
        对方确认是新版、又嫌码长，就用这个。

  码为什么那么长：长度几乎全花在注释上。一条 22 步、带 8 句讲解的轴，
  完整要 1000 多字符。嫌长就删掉几条注释再分享，或者让对方升级后用压缩。

  导入可以不干净：整段聊天记录直接粘进来也行，
  程序会自己把 RP2:/RP3: 后面那串挑出来，前后的「兄弟给你」「谢谢」不影响。

  导入弹窗底下就三个按钮：共享文档 / 预览 / 导入。
    · 预览：在下面把这条轴按编轴时一模一样的样子画出来（分段、反复、
      注释、技能格都在），先看清楚再决定。
    · 导入：直接用。点过预览的话不重复解析，粘的码一改预览就收起。

  导出 JSON
        同一个弹窗里有「导出 JSON」按钮，把这条轴存成一个 .json 文件
        （轴名、编队、长按毫秒、全部步骤都在里面），原样保存、随时能看能改。
        这个文件的内容也能直接粘进「导入」——整段 JSON 粘进去照样能导，
        不用非得转成分享码。轴库备份文件（带 teams 的那种）不行，
        它要走「技能轴库 → 恢复」。

  共享文档
        分享弹窗、导入弹窗的左下角都有「共享文档」按钮，点开就是作者的
        腾讯文档（轴库、干员资料都在那儿），不用退出去找顶栏那个按钮。
        导入的时候手里还没有码，也可以直接去那儿翻。

  对方点「导入」粘贴分享码，什么都不用填：
    · 编队和整条轴立刻还原（含反复记号、长按毫秒）；
    · 一定存进技能轴库 —— 码里没带名字也会自动起一个
      （「伊冯+汤汤 · 10-26 12:30」这种），重名自动加 (2)；
      连着导两条也不会互相顶掉（以前只有带名字的码才入库，没名字的
      只顶掉当前轴，再导一条前一条就没了）；
    · 同时把那 4 个人存成一套编队（编队库里还没有的话），
      编队名就是这几个人的名字，不再依赖轴名；
    · 导完自动切回「显示全部轴」，不会因为之前点过某套编队，
      新导进来的轴被筛掉、看着像没存；
    · 导错了按 Ctrl+Z 能退回导入前的那条轴；
    · 码里一个技能格都没有的，会提示「没有导入」，不动你当前的轴。

  分享码里的编队只存了「名单里的第几号」：要是你编队里有谁不在干员名单里
  （改过名、或者对方的包没这个人），码里那位会变成空位。这种情况
  点「分享码」时会直接弹提示告诉你，不会悄悄丢掉。

  分享码前缀默认是 RP2:（跟作者原版一致），所以作者原版、群友的旧版都能导入；
  名字藏在码的末尾，老版本读到时自动忽略，不会报错。
  注：旧版本能解出轴，但认不出「反复记号」（会当成分段标签）。

干员包
  别人做的 .zip 干员包，用「添加干员」选中即可导入，
  导入后卡面和技能图标会自动生成。

十二、常见问题
--------------------------------------------------
提示条不出现 / 按了没反应
  多半是没有管理员权限。关掉程序，右键「启动.bat」→ 以管理员身份运行。
  现在主界面会自己报：设置 → 关于 →「权限 / 排错」，
  显示「管理员权限 ✓」就没问题；显示「未获管理员权限」就是没提权成功，
  打开程序时还会弹一句提醒。

想知道刚才到底出了什么错
  设置 → 关于 →「权限 / 排错」→「查看最近日志」，会把最近 40 行运行日志列出来，
  可以一键复制，发给作者时比自己描述现象有用得多。

点了保存 / 开始运行没反应，底部还出现红条
  后台进程没了（黑窗口被关掉）。关掉主窗口，重新双击「启动.bat」。

分享码导入报错
  报「不完整或已损坏」= 复制的时候漏字符了，重新整段复制；
  报「太长」= 贴错了东西（比如整篇文档），不是分享码；
  报 bad base85 character at position 3 = 对方发的是 RP3 格式，
  你这台版本太老读不了。让对方改用 RP2 重新导一次。

手柄没反应
  见第七节。

界面显示不全 / 图标空白
  先把主界面窗口拉大一点；仍旧异常就重启程序。

程序打不开
  确认文件夹没被杀毒隔离、解压完整（runtime 文件夹要在）。

换电脑
  整个文件夹复制过去，双击「启动.bat」；
  自己的轴和编队可以先用「分享码」导出备份。

十三点五、新版本和新干员
--------------------------------------------------
顶栏「新版本和新干员」点开两项：

  GitHub 更新    检查最新版本，一键下载并更新（保留 config.json）
  更新干员       从最新 Release 拉干员包（operators_*.zip）并自动导入

十四、关于更新
--------------------------------------------------
  以后小改动会以「补丁包」的形式发在群文件，只有几十 KB，
  不用重新下载整个程序。

  本增强补丁怎么装：
    把 EndfieldRotPilot 文件夹拖到「打补丁.bat」上，松手，等它跑完；
    或把压缩包解压到游戏文件夹里，双击「打补丁.bat」。
    装完关掉原来的窗口，重新双击「启动.bat」。

  它和程序内的「设置 → 导入补丁」不是一回事：
    程序内那个是整文件覆盖，只认整份文件的补丁包；
    本补丁是按代码块注入，作者更新版本后把新文件夹拖上去重打一次即可，
    打不上的地方会明确列出来，不会把文件写坏。
    补丁前会自动备份到 _补丁备份\时间\，「撤销补丁.bat」可还原。

先选 DS / Xbox（会自动识别），下拉里只会有这套手柄能用的键。
连携技可以单独选：Xbox 支持 A / B / X / Y（也可以选 LB / RB / LT），
DS 支持 L1 / R1 / L2。运行条按「手柄」显示时，会同步显示你选的这些键。

十五点五、更新后文件夹会自动改名
--------------------------------------------------
如果程序所在文件夹名字里带版本号，更新完会自动改名：

  例：EndfieldRotPilot_v1.3.9_test\EndfieldRotPilot
  更新到 v1.4 后变成
      EndfieldRotPilot_v1.4\EndfieldRotPilot

  · 只改名字，里面东西不动
  · 目标文件夹已存在就不改，免得覆盖你别的副本
  · 不带版本号的文件夹保持原样

十六、更新会不会丢数据
--------------------------------------------------
不会。更新时：
  · config.json（编队、轴、队库、键位）不会被覆盖
  · 更新前还会自动把 config.json 复制一份成 config.json.bak
  · 先解压到临时目录，成功后才覆盖程序文件
万一更新中途断电，程序还是旧版，重开再更新一次就行。

十五、版本与排错
--------------------------------------------------
设置 → 关于：

    版本号（当前 v1.3.42）、构建日期；
    「看这一版更新了什么」打开更新说明；
    「关闭窗口时退出程序」勾上以后，点 × 就等于彻底退出（默认不勾）；
    「更新 / 补丁」里可以直接导入补丁包，或还原上一个版本。

设置 → 关于 →「权限 / 排错」：
    显示当前是不是管理员；
    「查看最近日志」把最近的运行日志调出来，可整段复制发给作者。

常见情况：
  · 运行条不出现：先看是不是没以管理员运行
  · 按了没反应：设置里「当前按下（实时）」有没有变化
  · 提示「后台进程没有响应」：黑框被关了，重开「启动.bat」

十六、设置面板（左侧六页）
--------------------------------------------------
设置改成左边导航、右边内容，不用再一路往下滚：

  运行条        长按判定、不透明度、图标大小、整体缩放、接下来 2 格
  屏幕与显示    放哪块屏、距顶部 / 水平位置、按键显示（键鼠 / 手柄）、
                当前技能突出显示（聚焦 / 框选 / 兼容）
  键盘          战技 1~4、终结技 1~4、连携技，以及 Q/E/Alt 的快速输入说明
  手柄          设备、实时按键、修饰键、1~4 号位面键、连携键
  快捷键        退出运行、重置、反复开关 / 回起点、变淡 / 变实
  关于          版本、更新说明、关窗是否退出、权限排错、更新 / 补丁

  改完点右下「保存」；直接点「关闭」不会丢已有设置。
  每次打开会停在上次看的那一页；窗口窄的时候导航会自动变成横排。

补充：不选中任何格子直接点「加注释」，会插入一条「纯注释」——
它不按键、只在运行条上显示这句话，跑轴时会自动跳过。
