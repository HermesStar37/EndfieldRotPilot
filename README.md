# Endfield RotPilot · 终末地技能轴

《明日方舟：终末地》的技能轴提示工具。

在游戏里叠一个提示条，告诉你下一步按什么键；按对了它才往前走，按错了不动。
不注入、不读内存、不改游戏文件，本质就是「按键捕捉 + 显示提示」。

---

## 这是什么

- 自己排一条技能轴（战技 / 连携 / 终结 / 重击 / 注释 / 换行 / 反复）
- 支持分段、嵌套反复、一个起点多个终点、无限循环
- 运行时在游戏画面上浮一条提示，按对了才推进
- 键鼠和手柄同时生效
- 分享码导入导出，带轴名、编队、注释、反复记号
- 技能轴库 / 编队库，可搜索、可备份

## 运行环境

- Windows 10 / 11（64 位）
- 需要管理员权限（读取游戏内按键需要）
- `runtime\` 是随包附带的 Python 3.12 便携版，无需另装

## 快速开始

1. 解压到任意目录（路径别带特殊符号）
2. 双击 `启动.bat`，弹权限窗口点「是」
3. 左边选 4 个干员
4. 右边用底部按钮加技能
5. 点右上「开始运行」，在游戏里跟着提示按

详细说明看 `说明.txt`，本版改动看 `本次更新.txt`。

## 键位（默认）

| 操作 | 说明 |
|---|---|
| `Q` + `1~4` | 战技 1~4 |
| `E` + `1~4` | 连携 1~4 |
| `Alt` + `1~4` | 终结技 1~4 |
| 长按 `1~4` | 终结技 1~4 |
| `H` | 重击 |
| `F8` / `F9` | 退出运行 / 回到第一段 |
| `F6` / `F7` | 提示条变淡 / 变实 |
| `F10` / `F11` | 临时开关反复 / 回反复起点 |

Q / E / Alt 都是**按住不放再按数字**，松开即失效；单独按数字不会插入技能。

手柄默认 DS（L1 修饰 / □△○× 四位 / R1 连携），可在设置里切到 Xbox，
连携技在 Xbox 上还可以选 A / B / X / Y。


## 分享与备份

- 「分享码」生成 RP2（兼容）/ RP3（压缩）两种码
- 「备份」把技能轴库 + 编队库导出成 json，「恢复」读回来
- 换电脑、重装前记得备份

## 常见问题

**提示条不出现**
检查是否以管理员身份运行；杀了游戏再试一次。

**按了没反应**
设置 → 手柄/键盘，看「当前按下（实时）」有没有变化。

**提示「后台进程没有响应」**
黑色命令行窗口被关了，重新双击 `启动.bat`。

**手柄读不到**
用管理员运行；有些游戏独占手柄，可装 DS4Windows 转成 XInput。
